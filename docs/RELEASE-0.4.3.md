# Your games do not need a store

Pame 0.4.3 brings standalone and extracted portable Windows games into your controller-friendly library, including classic games that never had a Steam release.

- **Find games on your PC:** scan drives or folders, review results and save locations for automatic discovery.
- **Drop a game folder onto Desktop:** Pame watches Desktop, Downloads and saved folders for changes and refreshes when no Pame-managed game is active.
- **Free metadata and artwork:** LaunchBox is the primary source, with Steam and local images as additional sources. No accounts, API keys or subscriptions.
- **Real game logos:** display transparent logos when available, plus box covers and backgrounds cached for offline use.
- **Correct a match with your controller:** choose the right edition, rename titles, and keep hidden games hidden across scans.
